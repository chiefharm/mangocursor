# SOCO Salon — AI-примерка стрижек и окрашивания (сессия 28.07.2026)

> Переписка Cloud Agent + Егор. Продолжить с компьютера: открыть этот файл и `SESSION_LOG.md`.

**Сайт:** [soco-salon.ru](https://soco-salon.ru)  
**Задача:** клиент загружает фото → выбирает стрижку/цвет из портфолио SOCO → видит AI-превью.

---

## 1. Исходный запрос

Хочется на сайте салона сделать AI-примерку:
- клиент грузит своё фото;
- выбирает из **портфолио** стрижку или цвет;
- получает превью «как будет выглядеть».

Упоминали [kie.ai](https://kie.ai/ru) как возможный вариант.

---

## 2. Архитектура (рекомендация)

```
Клиент на soco-salon.ru
    ↓ фото + выбор работы из портфолио
Backend-прокси (VPS, API-ключи не в браузере)
    ↓
AI API
    ↓
Результат + кнопка «Записаться»
```

**Два режима в UI (не смешивать в одном запросе):**

| Режим | Вход | API |
|-------|------|-----|
| Стрижка | фото клиента + **фото работы из портфолио** | hair transfer / reference image |
| Окрашивание | фото клиента + цвет или референс | hair color API |

**Портфолио SOCO** — главное преимущество: каждая работа = `style_id` + URL фото мастера.

---

## 3. Kie.ai — для MVP, не для «салонного» продакшена

**kie.ai** — агрегатор моделей (GPT Image, Ideogram, Wan 2.7 и др.), не специализированный hair try-on.

| Подход | Плюсы | Минусы |
|--------|-------|--------|
| Ideogram Character Edit | сохраняет лицо, дёшево | нужно тестировать на ваших работах |
| Wan 2.7 | гибкий портрет | менее предсказуемо |
| Image-to-Image | быстрый прототип | плохо переносит **конкретную** работу из портфолио |

**Вывод:** kie.ai — для экспериментов; для стабильности на сайте — другие API.

---

## 4. Сравнение для продакшена (стабильность «как Style My Hair»)

### L’Oréal Style My Hair
- Движок **ModiFace** (дочка L’Oréal), enterprise, API для сторонних салонов **не продаётся** публично.

### Perfect Corp / YouCam — **рекомендация для SOCO**
- API **Hairstyle** + **Hair Color**
- **`ref_file_url`** — фото из вашего портфолио как референс ✅
- Тот же движок, что [онлайн-демо](https://yce.perfectcorp.com/ai-hairstyle-generator) (200+ стилей + «Upload Hairstyle»)
- Регистрация: [yce.perfectcorp.com/ai-api](https://yce.perfectcorp.com/ai-api) → Get Free API Key
- Playground: [API Playground](https://yce.makeupar.com/api-console/en/api-playground/ai-hair-style-generator/)

### AILab Tools — дешевле, но слабее под задачу
- Только **пресеты** (`LongWavy`, `BobCut`, …), **без** загрузки работы из портфолио ❌
- В доках: *«каждый раз разный результат для одной стрижки»* — ниже стабильность
- ~$0.05 за примерку (10 credits)
- Демо: [ailabtools.com/hairstyle-changer](https://www.ailabtools.com/hairstyle-changer)

| | Perfect Corp | AILab Pro |
|---|--------------|-----------|
| Референс из портфолио | ✅ | ❌ |
| Стабильность | высокая | средняя |
| Цена | дороже | ~$0.05/запрос |
| Цвет | отдельный API | ~20 пресетов |

**Итог:** для soco-salon.ru с выбором из портфолио → **Perfect Corp**.

## 5. Тестирование (28.07.2026)

Cloud Agent **не смог** сгенерировать картинки — оба API требуют ключ:

| API | Endpoint | Ответ без ключа |
|-----|----------|-----------------|
| Perfect Corp | `yce-api-01.makeupar.com/s2s/v2.1/task/hair-transfer` | `401 Invalid API Key` |
| AILab | `ailabapi.com/.../hairstyle-editor-pro` | `Invalid API key` |

### Как протестировать самому (30 мин)

1. **Perfect Corp:** регистрация → API Key → Playground → 5–10 пар «селфи клиента + фото работы SOCO».
2. **AILab (опционально):** онлайн-демо или API от $12.
3. **Скрипт сравнения:** `tools/hair_tryon_test/run_comparison.py`

```bash
export PERFECTCORP_API_KEY="..."
export AILAB_API_KEY="..."   # опционально

python3 tools/hair_tryon_test/run_comparison.py \
  --selfie path/to/selfie.jpg \
  --ref path/to/portfolio_work.jpg \
  --out results/
```

### Чеклист качества
1. Лицо без «пластиковой» маски?
2. Линия роста волос естественная?
3. Стрижка/цвет похожи на референс из портфолио?
4. Освещение согласовано с исходным фото?
5. Повторный запрос даёт стабильный результат?
